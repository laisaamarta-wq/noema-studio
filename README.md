# NOEMA® — Immersive Digital Studio

Concept website for a fictional next-generation digital studio. One living material — liquid chrome, iridescent glass, obsidian crystal — changes state as you scroll: a bubble drop, a particle nebula, a field of chrome atoms, four discipline sculptures, a neural gallery and a cloud raining light onto water.

**Concept, art direction & design:** Marta Jakovleva

- Real-time WebGL (Three.js) with custom GLSL shaders, one canvas for the whole site
- Press & hold anywhere to condense particles into a chrome bead
- Interactive work covers (neural network, chrome burst, glass petals, liquid metal) with case views
- Lab: switch the material between Chrome, Iris and Obsidian
- Living variable typography (Archivo), magnetic UI, cursor light trail, click shockwave
- Mobile-first touch interactions, reduced-motion support

Static site, no build step: `index.html`.
